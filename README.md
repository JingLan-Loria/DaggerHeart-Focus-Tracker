# DH聚焦追踪器

一个基于 Python + tkinter 的桌面回合计数工具，适用于匕首心跑团规则下记录聚焦与回合进度。

## 功能特性

- 可视化角色卡片：添加 / 删除角色，点击头像可更换自定义图片，点击名称可编辑
- 聚焦次数全局调节（2-10应该也用不到更少或更多的聚焦次数了吧），新添加角色会自动同步当前次数
- 计数点从左到右依次标记，全部标记自动进入新回合并弹窗提示
- 撤销 / 重做（Ctrl+Z / Ctrl+Y）：支持单点标记与回合重置的撤销重做
- 聚焦记录面板：方便回溯和全局浏览
- 设置方案：可保存 / 使用角色头像、名称与聚焦次数的组合方案
- 关闭程序时自动清除记录缓存
